Banking Customer Risk & Loan Intelligence

Project Overview

An end-to-end banking analytics project designed to analyze customer demographics, account activity, transaction patterns, loan performance, and credit risk using SQL, Python, and Power BI.

The project transforms banking datasets into meaningful business insights to help understand lending performance, outstanding loan exposure, and customer risk patterns.

Project Objectives

* Analyze customer demographics and banking activity.
* Evaluate loan performance and outstanding loan amounts.
* Identify loan defaults and understand default patterns.
* Analyze customer income, age groups, and loan types.
* Examine monthly transaction trends.
* Build interactive Power BI dashboards for banking risk analysis.

Technologies Used

* SQL: Data querying and banking risk analysis.
* Python: Data preparation and exploratory data analysis.
* Pandas and NumPy: Data manipulation and analysis.
* Matplotlib and Seaborn: Data visualization.
* Power BI: Interactive dashboards and business intelligence.
* Jupyter Notebook: Python analysis environment.

Dataset Overview

The project uses four synthetic banking datasets:

Dataset -Records

Customers - 10,000

Accounts - 13,000

Transactions - 5,000

Loans - 2,000

These datasets contain customer demographics, account information, transaction records, and loan details.

SQL Analysis

SQL was used to investigate banking and lending performance, including:

* Loan status distribution.
* Defaulted and outstanding loan amounts.
* Loan performance by loan type.
* Customer loan exposure.
* Customer demographics and lending patterns.
* Banking risk indicators.

Python Analysis

Python was used for data preparation, exploratory data analysis, and statistical investigation of banking datasets.

The analysis explored loan defaults, interest rates, loan types, customer income, age groups, outstanding amounts, and customer-level lending exposure.

Power BI Dashboard

The interactive Power BI dashboard presents key banking performance indicators and risk insights.

Key visualizations include:

* Customer and loan KPIs.
* Loan status distribution.
* Loan default rate by age group.
* Outstanding loan amounts by age group.
* Monthly transaction amount trends.
* Transaction counts by transaction type.
* Loan defaults by loan type.
* Total loans and outstanding amounts by loan type.
* Loan default analysis by income group.

Key Findings

The dataset contains 2,000 loans, including 190 defaulted loans.

The overall loan default rate is 9.5%.

The analysis also examines outstanding loan exposure, transaction activity, and differences in loan performance across customer segments.

These findings describe the synthetic dataset and should not be interpreted as real-world banking statistics.
